## 🎧 Features

- **Filename & Metadata Sanitization**: Removes noise, URLs, and unwanted prefixes from track titles.
- **Batch Processing**: Recursively cleans entire audio directory structures in seconds.
- **Dry-run Mode**: Preview renaming and tag modifications prior to executing on disk.

---

## 🚀 Installation & Usage

```bash
# 1. Clone repository
git clone https://github.com/ajaysaagar-dev/Songs-Cleaner.git
cd Songs-Cleaner

# 2. Install dependencies
npm install

# 3. Run audio cleaner
node index.js
```
